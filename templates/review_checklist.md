# Review Checklist

- Read `agents.md`.
- Read `WORKFLOW.md`.
- Read `LESSONS.md`.
- Read the most recent relevant `TASK_LOG.md` entries.
- Restate the task in plain language.
- List assumptions separately from facts.
- Decide whether the task is trivial, normal, complex, or high-risk.
- Select the smallest useful set of subagents.
- Confirm the validation plan before implementation.
- Check for hidden coupling or unrelated changes.
- Verify the result before claiming completion.
- Record any new reusable lesson or one-off observation.
